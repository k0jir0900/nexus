# NEXUS

Un lugar donde viven listas EDL (External Dynamic List) listas para usar.

La idea es simple: mantener en un solo sitio, publico y siempre accesible,
colecciones de datos que los firewalls y otras herramientas de seguridad
consumen a diario. IPs, dominios, URLs y lo que haga falta, cada tipo con su
propia lista y actualizadas cuando hay algo nuevo que agregar.
